# SimNDT Modern 功能状态

| 功能域 | 2.0 状态 | 说明 |
|---|---|---|
| 2D P/SV 弹性传播 | 已实现并验证 | 交错速度–应力格式 |
| 相控阵几何 | 已实现 | 物理宽度、pitch、kerf、子网格权重 |
| 聚焦/偏转/加窗 | 已实现 | 解析分数延迟，无整数采样量化 |
| 逐阵元接收与 DAS | 已实现 | 原始 RF 永久保留 |
| FMC | 已实现 | 单阵元依次发射、全阵元接收 |
| TFM | 已实现基础版 | 均匀介质 P 波走时 |
| P/SV 极化源 | 已实现 | 法向或切向表面牵引 |
| 自由表面 | 已实现 | 离散零牵引顶面 |
| CPML | 已实现并验证 | 8 mm 基准低于 -50 dB |
| 圆形空洞 | 已实现 | 低阻抗、零剪切模量声学填充 |
| 多材料/楔块/流固耦合 | 待实现 | 异质走时和真实探头需要此项 |
| 黏弹性衰减 | 待实现 | Kelvin–Voigt/广义 Maxwell |
| 3D 阵列/elevation focus | 待实现 | 二维结果不得冒充三维声场 |
| 动态接收聚焦 | 待实现 | 当前为固定焦点 DAS |
| 异质介质 TFM | 待实现 | 需要 eikonal/full-wave 走时 |
| NumPy | 原生严格内核 | 正确性基线 |
| CuPy | 原生严格内核 | CUDA 数组计算 |
| Numba/Cython/OpenCL | 严格兼容路径 | 旧同位网格内核被停用，等待重新优化 |

后续优先级：多材料与楔块 → 黏弹性 → 动态接收聚焦/异质 TFM → 原生 Numba/Cython/OpenCL CPML 优化 → 三维求解器。
