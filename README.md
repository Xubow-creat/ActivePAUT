# ActivePAUT

Simulation-first research code for **active (embodied) phased-array ultrasonic testing**. A Bayesian particle belief over a planar crack `(x, z, L, θ)` is updated with a complex scattering-matrix likelihood, and the next probe position is chosen by expected information gain (EIG). The code covers the fast forward model, the planner and baselines, the high-fidelity elastic-wave "world" (SimNDT-modern), the pre-registered tests (v2, v3, v4), the verification against exact solutions and open measured data, and the figure scripts.

超声相控阵「主动感知」研究代码：以复数散射矩阵似然更新裂纹 `(x, z, L, θ)` 的粒子信念，并用期望信息增益选择下一个探头位置。仿真优先，不含实验设备数据。

## Layout

| Path | Content |
|---|---|
| `10_ActivePAUT代码/activepaut_sim_v01/` | Main package `apsim/` (forward model, belief, planner, TFM, SimNDT adapters) and about 120 `run_*`, `analyze_*`, `check_*`, `make_*` scripts. Start with its `README.md`. |
| `10_ActivePAUT代码/activepaut_sim_v01/results/` | Only frozen protocols (`protocol*.json` with SHA-256), `analysis.json` summaries and the regression reference. Raw records and figures are not in git. |
| `10_ActivePAUT代码/arim_api/` | Snapshot of [arim](https://github.com/ndtatbristol/arim) (MIT), used as an independent reference for crack scattering and immersion rays. |
| `02_SimNDT弹性波仿真/SimNDT-modern/` | 2-D P–SV elastic solver with phased-array support, used as the high-fidelity world. |

The relative positions of these folders matter: scripts locate each other through `Path(__file__).parents[...]`. Do not move them apart.

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cd 10_ActivePAUT代码/activepaut_sim_v01
python3 -m tests.test_core
```

The fast world needs only NumPy and Matplotlib. `requirements-extra.txt` lists what individual scripts need (SciPy and h5py for arim, PyTorch for the CNN baseline, MLX for the Apple-silicon world generator). SimNDT-modern needs Python 3.11 or newer; install it from its own `pyproject.toml`.

## What is not included

- **Data and raw results.** Simulated worlds (`results/hifi_modern`, 3.3 GB), twin-specimen records, CNN checkpoints and video are regenerated by the `run_*.sh` scripts, for example `run_modern_world_mac.sh` and `run_v4.py`.
- **External measured data.** Strathclyde FMC (Lardner 2015) and Bristol data.bris bundles are downloaded separately and placed in `05_实测数据分析/`. See `THIRD_PARTY.md`.
- **The sealed specimen layout.** `make_specimen_design.py` runs in demo mode by default; the secret seed and `*SEALED*` files are excluded by `.gitignore`.
- **Manuscripts.**

## Known issue

`tests.test_core` has 15 tests. 14 pass in the Linux sandbox (Python 3.10, NumPy 2.2.6). `test_obs_mag_reproduces_v01` fails: it compares a closed-loop trajectory bit for bit with `results/regression_obs_mag.json`, which was written on the Mac. The failure is the same on the original workspace files and on this copy, so the upload did not cause it. The likely cause is a different NumPy or platform floating-point path; this has not been checked. Because `python3 -m tests.test_core` stops at the first failure, run the tests through pytest or a loop (as in `tests/`) to see the rest.

## Protocol integrity

Each pre-registered test stores its frozen protocol and a SHA-256 next to it (`results/{hard_regimes,confirm_v3,v4,twin}/protocol*.json` and `.sha256`). `analysis.json` records the hash of the protocol it was computed from.
